# Michi 디자인 시스템

## 제품 분위기

Michi는 서울을 방문하는 일본인 여행객을 위한 차분하고 실용적인 여행 계획 도구다. 장식적인 여행 랜딩 페이지보다 가독성, 신뢰, 데이터 출처 상태, 빠른 편집을 우선한다.

## 기반

- 캔버스: 따뜻한 미색 `#F7F5EF`, 표면: 흰색
- 주 색상: 짙은 녹색 `#0F6253`, 강조 색상: 테라코타 `#BD4C31`
- 본문 색상: 검정에 가까운 녹색 `#16231F`, 보조 본문: `#5B6863`
- 오류, 경고, Mock, Live 상태는 색상에만 의존하지 않고 항상 텍스트를 함께 표시한다.
- 본문: 시스템 일본어 산세리프 16px/1.55, 표시 제목: Georgia/Yu Mincho
- 모서리 반경: 6–8px. 카드는 반복되는 장소와 플래너 도구에만 사용한다.
- 데스크톱 콘텐츠 너비: 1120px, 읽기·폼 너비: 760px

## 상호작용

- 모든 상호작용 영역은 최소 44×44px로 만든다.
- 키보드 포커스에는 눈에 보이는 3px 파란색 외곽선을 사용한다.
- 모션은 180ms 상태 피드백으로 제한하고, 모션 감소 설정에서는 비활성화한다.
- 폼은 항상 보이는 label, 입력 근처 오류, 실패 후 입력값 유지를 제공한다.
- 비동기 흐름에는 로딩, 실패, 비활성화, 빈 상태, 성공·결과 상태를 제공한다.

## 컴포넌트

- 기본 버튼: 짙은 녹색 배경과 흰색 label
- 보조 버튼: 흰색 배경, 어두운 label, 명확한 테두리
- 위험 버튼: 흰색 배경, 빨간색 label과 테두리
- 제공자 chip: 제공자 이름과 명시적인 `LIVE`, `MOCK`, `UNAVAILABLE` 텍스트
- 장소 카드: 카테고리, 검증된 제공자 이름, 추천 이유, 사실 정보, 지역 단위 혼잡 범위, 접을 수 있는 점수 내역, 편집 동작 순으로 구성
- 타임라인: 명확한 시각, 번호 순서, 의미에 맞는 순서 목록 사용
- 지도 대체 화면: 좌표 목록과 설정 경고를 표시하며, 실제 동작하는 지도처럼 보이게 만들지 않는다.

## 반응형 동작

- 모바일: 한 열 구성, 지도 다음 타임라인 순서, 동작 버튼은 줄바꿈 후에도 접근 가능하게 유지
- 데스크톱: 왼쪽 타임라인, 오른쪽 고정 지도
- 좁은 화면에서는 폼을 한 열로 구성하고 760px 이상에서는 네 개의 간결한 제약조건 필드를 배치
- 어떤 콘텐츠도 hover에 의존하지 않으며 가로 스크롤이 필요하지 않게 구성
